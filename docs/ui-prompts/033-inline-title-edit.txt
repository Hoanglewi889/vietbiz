[요소] 제목 바로 고치기 (033, 입력·검색)
[요소 설명] 제목을 누르면 같은 글꼴 그대로 입력칸이 되고, 아래 밑줄이 왼쪽부터 그어집니다. Enter로 저장하면 초록 빛이 훑고 지나가며 수정 시간이 바뀌고, Esc를 누르면 원래 제목으로 돌아갑니다.
[조작] 제목이나 연필 아이콘을 눌러 고쳐 보세요. Enter로 저장, Esc로 취소합니다

아래 UI 요소를 제 프로젝트에 적용해 주세요.

[먼저 확인할 것]
1. 프로젝트의 프레임워크(React, Next, Vue, Svelte, 순수 HTML 등), 스타일 방식(CSS 모듈, Tailwind, 전역 CSS), 기존 테마 방식(data-theme, dark 클래스, CSS 변수)을 찾아 확인하세요.
2. 삽입 위치의 파일과 기존 요소를 먼저 찾고, 그 요소가 어디서 쓰이는지 보고하세요.

[적용 방법]
3. 삽입 위치에 새 컴포넌트로 추가하세요. 교체 대상이 있으면 그 요소를 아래 요소로 바꾸세요.
4. 기존 데이터, props, 이벤트 핸들러, 폼 값, 접근성 속성(라벨, aria, 키보드 조작)은 그대로 유지하세요.
5. 아래 코드의 구조, 형태, 모션 값(시간, 곡선, 지연)을 기준으로 옮기세요. 프레임워크에 맞게 컴포넌트와 상태로 바꾸되, 디자인을 새로 추측해 바꾸지 마세요.
6. 색은 아래 --ux-* 토큰을 프로젝트의 기존 테마 변수에 연결하세요. 라이트와 다크 두 값을 모두 유지하고, 두 테마에서 확인하세요.
7. 스타일은 이 요소의 클래스(.uNNN) 안에만 두고, 전역 CSS나 전역 스크립트는 바꾸지 마세요. 클래스 이름이 기존 요소와 겹치지 않게 하세요.
8. 예시 문구와 예시 데이터는 프로젝트의 실제 데이터로 바꾸세요. 갤러리 전용 화면과 시연 코드는 가져오지 마세요. 코드 맨 위의 라이선스 주석 한 줄은 새 컴포넌트 파일 맨 위에 남겨 두세요.
9. prefers-reduced-motion을 켠 상태에서도 기능과 최종 상태가 그대로 작동하는지 확인하세요.

[완료 보고]
10. 변경한 파일 목록, 기존 요소와 달라진 동작, 확인한 범위(두 테마, 모바일 너비, 키보드), 확인하지 못한 항목을 알려 주세요.

[삽입 위치] 여기에 페이지나 컴포넌트 이름을 적으세요
[교체 대상] 기존 요소의 파일 경로나 컴포넌트 이름을 적으세요. 없으면 "없음"

<script>
(function () {
  var root = document.currentScript.previousElementSibling;
  var view = root.querySelector('.u033-view');
  var pen = root.querySelector('.u033-pen');
  var input = root.querySelector('.u033-in');
  var ok = root.querySelector('.ok'), no = root.querySelector('.no');
  var when = root.querySelector('.u033-when');
  var title = view.textContent;
  function edit() {
    root.classList.add('is-edit');
    input.value = title;
    input.focus();
    input.select();
  }
  function shake() { root.classList.remove('is-shake'); void root.offsetWidth; root.classList.add('is-shake'); }
  function done(save) {
    if (!root.classList.contains('is-edit')) return;
    var v = input.value.trim();
    if (save && !v) { shake(); input.focus(); return; }
    root.classList.remove('is-edit');
    if (save && v !== title) {
      title = v;
      view.textContent = v;
      view.setAttribute('aria-label', '제목 고치기: ' + v);
      view.classList.remove('flash'); void view.offsetWidth; view.classList.add('flash');
      when.textContent = '방금 저장됨';
      when.classList.add('is-new');
    } else if (!save) shake();
    view.focus();
  }
  view.addEventListener('click', edit);
  pen.addEventListener('click', edit);
  ok.addEventListener('click', function () { done(true); });
  no.addEventListener('click', function () { done(false); });
  input.addEventListener('keydown', function (e) {
    if (e.isComposing || e.keyCode === 229) return;
    if (e.key === 'Enter') { e.preventDefault(); done(true); }
    if (e.key === 'Escape') { e.preventDefault(); done(false); }
  });
  // 바깥을 누르면 고친 내용을 저장합니다
  input.addEventListener('blur', function () { setTimeout(function () { if (root.isConnected && !root.contains(document.activeElement)) done(true); }, 0); });
})();
</script>
