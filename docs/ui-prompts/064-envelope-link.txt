[요소] 봉투로 보내는 로그인 링크 (064, 로그인·가입)
[요소 설명] 링크 받기를 누르면 편지가 봉투 속으로 내려가고 덮개가 닫힌 뒤 봉투가 날아갑니다. 이어 ‘메일함을 확인하세요’ 화면이 열리고, 다시 보내기는 링이 다 찰 때까지 잠겨 있습니다.
[조작] 이메일을 확인하고 ‘로그인 링크 받기’를 눌러 보세요. 보낸 뒤에는 다시 보내기 잠금과 ‘다른 이메일 쓰기’를 눌러 처음으로 돌아갈 수 있습니다

아래 UI 요소를 제 프로젝트에 적용해 주세요.

[먼저 확인할 것]
1. 프로젝트의 프레임워크(React, Next, Vue, Svelte, 순수 HTML 등), 스타일 방식(CSS 모듈, Tailwind, 전역 CSS), 기존 테마 방식(data-theme, dark 클래스, CSS 변수)을 찾아 확인하세요.
2. 삽입 위치의 파일과 기존 요소를 먼저 찾고, 그 요소가 어디서 쓰이는지 보고하세요.

[적용 방법]
3. 삽입 위치에 새 컴포넌트로 추가하세요. 교체 대상이 있으면 그 요소를 아래 요소로 바꾸세요.
4. 기존 데이터, props, 이벤트 핸들러, 폼 값, 접근성 속성(라벨, aria, 키보드 조작)은 그대로 유지하세요.
5. 아래 코드의 구조, 형태, 모션 값(시간, 곡선, 지연)을 기준으로 옮기세요. 프레임워크에 맞게 컴포넌트와 상태로 바꾸되, 디자인을 새로 추측해 바꾸지 마세요.
6. 색은 아래 --ux-* 토큰을 프로젝트의 기존 테마 변수에 연결하세요. 라이트와 다크 두 값을 모두 유지하고, 두 테마에서 확인하세요.
7. 스타일은 이 요소의 클래스(.uNNN) 안에만 두고, 전역 CSS나 전역 스크립트는 바꾸지 마세요. 클래스 이름이 기존 요소와 겹치지 않게 하세요.
8. 예시 문구와 예시 데이터는 프로젝트의 실제 데이터로 바꾸세요. 갤러리 전용 화면과 시연 코드는 가져오지 마세요. 코드 맨 위의 라이선스 주석 한 줄은 새 컴포넌트 파일 맨 위에 남겨 두세요.
9. prefers-reduced-motion을 켠 상태에서도 기능과 최종 상태가 그대로 작동하는지 확인하세요.

[완료 보고]
10. 변경한 파일 목록, 기존 요소와 달라진 동작, 확인한 범위(두 테마, 모바일 너비, 키보드), 확인하지 못한 항목을 알려 주세요.

[삽입 위치] 여기에 페이지나 컴포넌트 이름을 적으세요
[교체 대상] 기존 요소의 파일 경로나 컴포넌트 이름을 적으세요. 없으면 "없음"

(function () {
  var root = document.currentScript.previousElementSibling;
  var ask = root.querySelector('.u064-ask'), done = root.querySelector('.u064-done'), inp = ask.querySelector('input'), box = ask.querySelector('.u064-box');
  var re = root.querySelector('.u064-re'), reLab = re.querySelector('span'), to = root.querySelector('.u064-to'), other = root.querySelector('.u064-link');
  var rm = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
  var WAIT = 30, raf = 0, ts = [];
  function later(fn, ms) { ts.push(setTimeout(function () { if (root.isConnected) fn(); }, rm ? 0 : ms)); }
  function clear() { ts.forEach(clearTimeout); ts = []; cancelAnimationFrame(raf); }
  // 다시 보내기 링은 남은 시간만큼 차오르고, 다 차면 버튼이 열립니다
  function countdown() {
    var t0 = performance.now();
    re.setAttribute('aria-disabled', 'true');
    (function step(now) {
      if (!root.isConnected) return;
      var el = (now - t0) / 1000, left = Math.max(0, Math.ceil(WAIT - el));
      re.style.setProperty('--p', Math.min(1, el / WAIT).toFixed(3));
      reLab.textContent = left ? '다시 보내기 · ' + left + '초' : '다시 보내기';
      if (left) raf = requestAnimationFrame(step); else re.setAttribute('aria-disabled', 'false');
    })(t0);
  }
  function setPane(sent) {
    ask.inert = sent; done.inert = !sent;
    done.setAttribute('aria-hidden', String(!sent));
    done.querySelectorAll('button').forEach(function (b) { b.tabIndex = sent ? 0 : -1; });
  }
  function send() {
    clear();
    to.textContent = inp.value.trim();
    root.classList.remove('sent');
    root.classList.add('sealed');
    later(function () { root.classList.add('fly'); }, 950);
    later(function () {
      root.classList.remove('fly');
      root.classList.add('sent');
      setPane(true);
      re.focus({ preventScroll: true });
      countdown();
    }, 1650);
  }
  ask.addEventListener('submit', function (e) {
    e.preventDefault();
    if (!/^[^@\s]+@[^@\s]+\.[^@\s]{2,}$/.test(inp.value.trim())) {
      box.classList.add('bad'); inp.setAttribute('aria-invalid', 'true');
      box.animate([{ transform: 'translateX(-6px)' }, { transform: 'translateX(5px)' }, { transform: 'none' }], { duration: 300 });
      return;
    }
    box.classList.remove('bad'); inp.removeAttribute('aria-invalid');
    send();
  });
  inp.addEventListener('input', function () { box.classList.remove('bad'); });
  re.addEventListener('click', function () {
    if (re.getAttribute('aria-disabled') === 'true') return;
    root.classList.remove('sent'); setPane(false);
    send();
  });
  other.addEventListener('click', function () {
    clear();
    root.classList.remove('sent', 'sealed', 'fly');
    setPane(false);
    inp.focus({ preventScroll: true }); inp.select();
  });
  setPane(false);
})();
</script>
