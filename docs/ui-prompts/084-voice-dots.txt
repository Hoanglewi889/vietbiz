[요소] 목소리에 춤추는 점 로더 (084, 로딩·진행)
[요소 설명] 마이크 버튼을 누르고 있는 동안 다섯 점이 목소리 크기에 맞춰 위아래로 늘어납니다. 손을 떼면 점들이 차례로 오르내리는 물결로 바뀌며 생각하는 중을 보여 주고, 이어 받아 적은 문장이 한 글자씩 나타납니다.
[조작] 마이크 버튼을 길게 누르고 있다가 떼 보세요. 키보드는 버튼에서 Space를 누르고 있다가 뗍니다

아래 UI 요소를 제 프로젝트에 적용해 주세요.

[먼저 확인할 것]
1. 프로젝트의 프레임워크(React, Next, Vue, Svelte, 순수 HTML 등), 스타일 방식(CSS 모듈, Tailwind, 전역 CSS), 기존 테마 방식(data-theme, dark 클래스, CSS 변수)을 찾아 확인하세요.
2. 삽입 위치의 파일과 기존 요소를 먼저 찾고, 그 요소가 어디서 쓰이는지 보고하세요.

[적용 방법]
3. 삽입 위치에 새 컴포넌트로 추가하세요. 교체 대상이 있으면 그 요소를 아래 요소로 바꾸세요.
4. 기존 데이터, props, 이벤트 핸들러, 폼 값, 접근성 속성(라벨, aria, 키보드 조작)은 그대로 유지하세요.
5. 아래 코드의 구조, 형태, 모션 값(시간, 곡선, 지연)을 기준으로 옮기세요. 프레임워크에 맞게 컴포넌트와 상태로 바꾸되, 디자인을 새로 추측해 바꾸지 마세요.
6. 색은 아래 --ux-* 토큰을 프로젝트의 기존 테마 변수에 연결하세요. 라이트와 다크 두 값을 모두 유지하고, 두 테마에서 확인하세요.
7. 스타일은 이 요소의 클래스(.uNNN) 안에만 두고, 전역 CSS나 전역 스크립트는 바꾸지 마세요. 클래스 이름이 기존 요소와 겹치지 않게 하세요.
8. 예시 문구와 예시 데이터는 프로젝트의 실제 데이터로 바꾸세요. 갤러리 전용 화면과 시연 코드는 가져오지 마세요. 코드 맨 위의 라이선스 주석 한 줄은 새 컴포넌트 파일 맨 위에 남겨 두세요.
9. prefers-reduced-motion을 켠 상태에서도 기능과 최종 상태가 그대로 작동하는지 확인하세요.

[완료 보고]
10. 변경한 파일 목록, 기존 요소와 달라진 동작, 확인한 범위(두 테마, 모바일 너비, 키보드), 확인하지 못한 항목을 알려 주세요.

[삽입 위치] 여기에 페이지나 컴포넌트 이름을 적으세요
[교체 대상] 기존 요소의 파일 경로나 컴포넌트 이름을 적으세요. 없으면 "없음"

(function () {
  var root = document.currentScript.previousElementSibling;
  var dots = root.querySelectorAll('.u084-dots i'), mic = root.querySelector('.u084-mic'), say = root.querySelector('.u084-say'), lab = root.querySelector('.u084-lab');
  var rm = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
  var ANS = ['내일 오전 10시에 디자인 리뷰 일정 추가해 줘', '이번 주 토요일 제주 날씨 알려 줘', '한도윤에게 시안 보냈다고 메시지 보내 줘'];
  var raf = 0, t0 = 0, ts = [], n = 0, held = false;
  function set(s, label) { root.setAttribute('data-s', s); lab.textContent = label; }
  // 듣는 동안에는 여러 사인파를 섞은 가짜 음량으로 점의 높이를 바꿉니다
  function listen(now) {
    if (!root.isConnected || root.getAttribute('data-s') !== 'listen') return;
    var t = (now - t0) / 1000, lv = 0;
    dots.forEach(function (d, i) {
      var v = Math.abs(Math.sin(t * 7 + i * 1.3) * 0.6 + Math.sin(t * 13 + i * 2.1) * 0.3 + Math.sin(t * 3.1) * 0.2);
      v = rm ? 0.4 : Math.min(1, v * (0.7 + 0.3 * Math.sin(t * 2 + i)));
      d.style.setProperty('--h', v.toFixed(3)); lv += v;
    });
    mic.style.setProperty('--lv', (lv / 5).toFixed(3));
    raf = requestAnimationFrame(listen);
  }
  function down() {
    if (held) return;
    held = true;
    ts.forEach(clearTimeout); ts = [];
    set('listen', '듣는 중');
    say.className = 'u084-say dim'; say.textContent = '말씀하세요…';
    t0 = performance.now(); cancelAnimationFrame(raf); raf = requestAnimationFrame(listen);
  }
  function up() {
    if (!held) return;
    held = false;
    cancelAnimationFrame(raf);
    dots.forEach(function (d) { d.style.setProperty('--h', 0); });
    mic.style.setProperty('--lv', 0);
    set('think', '생각하는 중');
    say.textContent = '';
    var txt = ANS[n++ % ANS.length];
    ts.push(setTimeout(function () {
      if (!root.isConnected) return;
      set('idle', '받아 적었어요');
      say.className = 'u084-say';
      // 받아 적은 문장은 한 글자씩 흘러나옵니다
      var k = 0;
      (function type() {
        if (!root.isConnected) return;
        say.innerHTML = '';
        say.appendChild(document.createTextNode(txt.slice(0, k)));
        if (k < txt.length) { var c = document.createElement('span'); c.className = 'c'; say.appendChild(c); k++; ts.push(setTimeout(type, rm ? 0 : 38)); }
      })();
    }, rm ? 300 : 1600));
  }

  mic.addEventListener('pointerup', up);

  mic.addEventListener('keyup', function (e) { if (e.key === ' ' || e.key === 'Enter') { e.preventDefault(); up(); } });
  mic.addEventListener('contextmenu', function (e) { e.preventDefault(); });
})();
